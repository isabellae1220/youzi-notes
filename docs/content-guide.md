# 内容录入规范

## 资料必填信息

- 唯一 ID
- 所属课程 ID
- 标题
- 资料类型
- 简介
- 文件格式
- 最后更新日期

## 可用资料类型

- `note`：整理笔记
- `exam`：已确认可公开的历年试卷或学生回忆版
- `exercise`：习题资料
- `summary`：复习总结
- `experiment`：可公开的实验整理

某门课没有的类型直接不创建数据。

## 公开前检查

- 资料是否由贡献者原创，或已获得公开授权？
- 是否包含学号、姓名、成绩、联系方式等信息？
- 是否来自付费渠道、内部系统或明确禁止传播的资料？
- 文件名、简介和所属课程是否清晰？

任何一项不确定时，暂不公开。
