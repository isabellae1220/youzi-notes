# 柚子 Notes：第一版架构决策

## 产品边界

第一版是一个只读、静态生成的校内课程资料库。用户可以按学院和课程浏览、预览和下载资料；贡献通过 GitHub Issue 提交，由维护者人工审核。

第一版不包含登录、评论、收藏、学习进度、用户上传和数据库。

## 技术选型

- React + Next.js
- TypeScript 严格类型
- Tailwind CSS 与项目自有样式变量
- 课程与资料使用结构化数据管理
- 笔记内容后续使用 Markdown/MDX
- PDF 等大文件保存在外部对象存储，仓库只记录链接
- 部署采用静态优先方式

## 内容原则

1. 只记录真实存在且可以公开的资料。
2. 没有的资料类型不建立空占位。
3. 未获授权的教师课件不录入、不显示。
4. 资料与页面组件分离，不将课程内容写死在界面中。
5. 所有公开资料必须通过版权与隐私检查。

## 全站视觉规则

- 全部页面使用统一的米色背景与黑色主操作。
- 课程卡和资料卡使用粉、杏、紫、浅绿四色循环。
- 同一行中的卡片尽量使用不同颜色，不同行可以重复。
- 新页面和新组件必须复用这套颜色变量，不再建立独立主题。

## 导航层级

```text
首页
└── 课程书架
    └── 学院
        └── 课程
            └── 已公开资料
```

## 路由

- `/`：首页
- `/courses`：学院与课程书架
- `/courses/[id]`：课程详情和资料列表
- `/about`：项目说明、版权与使用规则
- `/contribute`：Issue 与 Pull Request 贡献指引

## 未来扩展边界

当真实需求出现时，再将内容数据源替换为 API 或数据库。页面层只依赖统一的课程与资料类型，不直接依赖具体存储实现。
